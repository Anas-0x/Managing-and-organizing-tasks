## Managing-and-organizing-tasks
It is a web application that allows people to organize their daily tasks or anything they want to do by simply adding the task to the website. The website contains many great features.

## Features
1. There are three lists: To Do, In Progress, and Done. I can easily add my tasks to any list I want by simply clicking the Add button and selecting the tasks I want to add.
2. When you close and reopen the site, all tasks are saved and in the same lists where you placed them.
3. Any task can be deleted with just one click.
